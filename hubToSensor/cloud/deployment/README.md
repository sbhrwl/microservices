# Deployment Process 
- `Kisters Cloud Registry` is publicly accessible and requires organization credentials to access artifacts securely.
- GitLab CI/CD pipeline will be configured to pull artifacts from the Kisters Cloud Registry and deploy them onto the GFC service project. 
- Resource creation and configuration is managed by KISTERS ConfigurationManager
  - `KISTERS ConfigurationManager` for `Infrastructure components`
  - `EnergyAnalytics` for `GFC components`
  - `Ansible` for `TSM+ components`
- **Configuration-as-code** is supported using the `headless-install` option by
  - ConfigurationManager for Infrastructure server
  - EnergyAnalytics for GFC application
  - Ansible for deployment of KISTERS TSM+ server
