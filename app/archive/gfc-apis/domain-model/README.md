# Domain model
- **Device management domain**
  - Device lifecycle and states
  - Device registration and inventory
  - Communication and connectivity
  - Data collection and completeness
- **Event management domain**
  - Event types and categories
  - Event retention and severity
  - Event sources and domains

- **Organization management domain**
  - Organization hierarchy
  - Settings and configuration
  - Warranty rules and policies

- **Tag management domain**
  - Tag creation and assignment
  - Device tagging strategies
  - Tag-based queries
